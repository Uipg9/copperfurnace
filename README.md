# Copper Furnace

A furnace made of copper that smelts faster while it is shiny. Like other copper blocks it oxidizes over
time and slows down; scrape it with an axe or wax it with honeycomb to keep the speed.

Fabric mod for Minecraft 26.3 (Java 25, Mojang names). Requires Fabric API only.

| Stage | Smelting speed | Ticks per item |
|---|---|---|
| Copper Furnace | 1.5x | 134 |
| Exposed | 1.35x | 149 |
| Weathered | 1.2x | 167 |
| Oxidized | 1.0x (vanilla) | 200 |

- Fuel burns proportionally faster, so each fuel item still smelts the vanilla number of items.
- Regular smelting recipes only (no blasting or smoking recipes).
- Recipe: a furnace surrounded by 8 copper ingots.
- Waxed versions never oxidize. Sneak and use an axe to scrape a stage or remove wax.
